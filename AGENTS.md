# Arbeit in diesem Repository

- README und vorhandene Dokumentation vor Änderungen lesen.
- Änderungen auf einem eigenen Branch mit Pull Request einreichen. Die Git- und YAML-Prüfung muss erfolgreich sein.
- Für eine Demo gilt DEMO als einzige dauerhafte Umgebung. Temporäre PR-Vorschauen bei Bedarf verwenden.
- Keine Kundendaten oder Zugangsdaten in Repository oder Logs ablegen.
