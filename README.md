# motivo-demo
Interaktive Demo für Autovermietung und Car Detailing mit lokalem Buchungsablauf.

Dieses Repository enthält die Dokumentation der Demo.

## Änderungen prüfen

Ein Pull Request nach `main` startet die Git- und YAML-Prüfung. Entwicklungsregeln und Freigaben sind in [AGENTS.md](AGENTS.md) beschrieben.
